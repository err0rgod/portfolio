The security model

A bridge between AI and your logged-in browser deserves paranoia

  • P-256 proof-of-possession for remote devices - pairing produces a revocable public-key identity. Every remote request binds to a fresh 32-byte daemon nonce + a SHA-256 digest of the canonical JSON, signed by the device key. Bearer tokens alone are never enough.
  • Two authority gates, by design - the browser's own per-site host permission (owned by Chromium, requestable only from a popup click) AND the daemon's capability+domain policy. Neither can bypass the other.
  • No blanket site access at install - http://*/* is an optional host permission the background worker is forbidden by code from requesting. Only a user's popup click can trigger the native prompt.
  • Confirmations are one-time, 60-second, operation-bound - approval is consumed by exactly one matching op, then gone. High-risk ops (file upload, debug evaluate) always require confirmation regardless of domain mode.
  • Redaction-first audit log - JSONL with a regex that catches token|password|secret|authorization|cookie|credential|private.?key|text|value plus any 32+-hex string, replaced with [redacted] before it ever touches disk.
  • Closed native-messaging allowlist - manifests only whitelist known extension IDs; unknown origins are rejected before the host reads a byte. New store IDs get trusted explicitly via conduit extension trust <id>.
  • Loopback-only default, hard-gated remote - the daemon refuses to start on a non-loopback bind unless remote.enabled AND TLS are both configured. No public relay; operators are pointed at Tailscale/WireGuard.
  • Ephemeral element IDs - snapshots stamp data-conduit-ref="e7" on DOM nodes and wipe them on the next snapshot. Stale selectors fail loudly instead of clicking the wrong thing.
  • Emergency disconnect - one popup button kills the daemon socket, stops auto-reconnect, and shows a red STOP badge until the user resumes.

From the code

The remote-request proof, condensed

// device signs: domain separation + challenge + request digest
const payload = [
  "conduit.remote.v1",
  challengeId,
  nonce,                          // 32 bytes, 30s ttl, single-use
  sha256(canonicalJson(request))  // binds proof to THIS exact request
].join("\n");

crypto.verify("sha256", payload, deviceP256Pubkey, signature)
// ✓ ⇒ short-lived session (15 min) · revocation kills sessions instantly
