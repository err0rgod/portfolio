### ZeroDaily
Autonomous tech intelligence platform & Inshorts-style news reader built on a multi-repo distributed architecture.
ZeroDaily is a full-fledged tech intelligence ecosystem delivering 60-word roasted summaries across 7 technical and financial domains. The platform is decoupled into four dedicated subsystems: an offline-first mobile app client, a serverless REST & push notification backend, an autonomous LLM ingestion and media engine, and an edge-deployed web showcase with dynamic release resolution.
* **Stack**: React Native / Expo SDK 52, TypeScript, FastAPI, Python 3.12, AWS Lambda, Amazon DynamoDB, Amazon S3, AWS Bedrock (DeepSeek v3.2), Cloudflare Pages & Edge CDN, Firebase Cloud Messaging (FCM), Vite, Docker
* **Subsystems & Multi-Repo Architecture**:
  - **Mobile App (`err0rgod/zerodaily-app`)**: Inshorts-style vertical gesture news reader built with React Native & Expo SDK 52. 0ms cold-boot renders from local disk storage, N-8 prefetch engine, hardware-accelerated WebP caching, FCM topic push alerts (topic_breaking_all & topic_{category}), and 100% cloud CI/CD APK compilation via GitHub Actions.
  - **Backend API & Notification Worker (`err0rgod/zerodaily`)**: High-performance FastAPI serving layer on AWS Lambda (via Mangum) backed by DynamoDB single-table design with GSIs for cursor-based ISO-8601 pagination. Cloudflare edge caching headers for 10–20ms global delivery. DynamoDB Streams worker with atomic 30-minute anti-spam cooldown locks via conditional writes & TTL dispatching breaking news to FCM HTTP v1 topics.
  - **Ingestion & Roasting Engine (`err0rgod/bot1`)**: Containerized Python 3.12 AWS Lambda pipeline triggered every 3 hours by EventBridge across 24+ feeds. Semantic LLM deduplication with AWS Bedrock DeepSeek v3.2 to eliminate ~75% of redundant fetches before extraction. Multi-tier scraping (cloudscraper + Firecrawl), XML prompt-injection sandboxing, zero-trust chunked media pipeline with SSRF guards and WebP optimization to S3, and automated 06:00 UTC executive morning digest with GB-seconds telemetry via Resend.
  - **Web Showcase & Release Portal (`err0rgod/zerodaily-web`)**: Minimalist Vite-powered SPA deployed to Cloudflare Pages edge. Dynamically resolves GitHub Releases API metadata to redirect (/apk, /download) directly to the latest production Android APK with interactive 60-word roast previews across 7 domains.

### Conduit
A local-first, security-conscious bridge between AI agents and a real browser.
Conduit connects MCP and CLI clients to a user's existing Chromium/Firefox profile through an authenticated local daemon and a Manifest V3 extension. It keeps browser policy, consent, and audit decisions on the user's machine while exposing structured accessibility trees and semantic element IDs.
* **Stack**: TypeScript, Node.js 22+, MCP, Manifest V3, Native Messaging, Zod, Playwright
* **Subsystems & Multi-Repo Architecture**:
  - **Core Daemon & CLI (`err0rgod/conduit`)**: Local-first authenticated daemon, MCP protocol adapter, P-256 pairing proof-of-possession, Zod runtime schema validation, narrow origin permissions, rate limiting, and redacted audit logs. Registers Native Messaging manifests across Chrome, Firefox, Edge, Brave, and Chromium.
  - **Browser Extension (`err0rgod/conduit-extension`)**: Manifest V3 extension generating accessibility snapshots with temporary numeric element IDs for resilient clicks, text input, and tab orchestration without brittle CSS selectors.
  - **Web Portal & Documentation (`err0rgod/conduit-web`)**: Documentation hub and portal on Cloudflare Pages.
* **Architecture**: AI agent (MCP / CLI) -> Authenticated Local Daemon (Node.js 22+) -> Native Messaging -> Extension (MV3) -> Browser Tab
* **Links**: [Live Site](https://conduit.zerodaily.in) | [Chrome Web Store](https://chromewebstore.google.com/detail/conduit-extension/gjhipjgiapijcdnflldnoenafeegmfpc) | [Firefox Add-on](https://addons.mozilla.org/en-US/firefox/addon/conduit/) | [Daemon Repo](https://github.com/err0rgod/conduit) | [Extension Repo](https://github.com/err0rgod/conduit-extension) | [Web Repo](https://github.com/err0rgod/conduit-web)

### FlexURL
Enterprise-grade URL shortening & link analytics platform with custom domain provisioning.
FlexURL is a production URL management platform built around FastAPI, PostgreSQL, and Redis. It pairs high-speed caching and Snowflake/Base62 link redirection with an asynchronous background analytics pipeline, automated Cloudflare for SaaS custom domain provisioning, and Google Safe Browsing malware detection.
* **Stack**: Python / FastAPI, PostgreSQL, SQLModel, Redis, ARQ Background Queue, Cloudflare for SaaS, Tailwind CSS, Nginx
* **Features & Architecture**:
  - High-performance Base62 redirects with Redis caching for instant redirection, password-protected links, expiry scheduling, and OS-specific routing.
  - Non-blocking ARQ background worker pipeline parsing Geo-IP, browser, device, and bot signatures before batch-flushing to PostgreSQL.
  - Programmatic multi-tenant custom domains via Cloudflare SaaS with automatic DNS CNAME verification and SSL certificate issuance.
  - Asynchronous Google Safe Browsing checks to flag and block malicious destinations.
  - Firebase Admin SDK authentication, JWT session cookies, Razorpay tier gating, API key management, and dynamic SVG GitHub visitor badges.

### blackwidow
Hardware HID takeover device bypassing Windows Defender Tamper Protection.
A specialized hardware attack device engineered on the ATtiny85 microcontroller (Digispark) for controlled penetration testing. It demonstrates physical-access threat vectors by automating GUI key sequences to disable Windows Defender Tamper Protection and Firewall, staging an elevated hidden reverse shell.
* **Stack**: C++ / ATtiny85, Arduino, DigiKeyboard, Hardware Security
* **Attack Chain & Mechanics**: 
  - Timed keyboard navigation via `DigiKeyboard.h` to navigate the Windows Security GUI and toggle off Tamper Protection (which cannot be disabled via command-line).
  - Automates privileged terminal execution (`Win+X` -> `A` -> `Y`) to launch an elevated administrative command prompt.
  - Disables Windows Firewall profiles and halts Real-time Monitoring via PowerShell.
  - Downloads a netcat binary into memory via PowerShell and establishes a hidden reverse shell (`-w Hidden`) back to the listener.
  - Comprehensive research documentation in the `Mafia/` subfolder detailing Windows 10/11 evasion mechanics.
* **Links**: [Source Code](https://github.com/err0rgod/blackwidow)
