§2why it exists

// every production service eventually needs a bouncer

  • Built from production scars - FlexURL's API serves tiered limits (60 / 180 / 600 req/min by plan) off a Redis token bucket; revlimiter packages that pattern so the next project doesn't re-derive it at 2 AM.
  • Pluggable storage - same duck-typed philosophy as tokenly: bring Redis, memcached, or anything with the right primitives. Your infra, your choice.
  • Framework-agnostic - a limiter is a predicate, not middleware religion. Wire it into FastAPI dependencies, Flask decorators, or a plain function call.
  • Actively evolving - this page exists because the project does; new algorithms and storage adapters land as my other systems need them.

from revlimiter import RateLimiter
