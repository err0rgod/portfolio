# ZeroDaily

React Native / Expo FastAPI AWS Lambda · DynamoDB Bedrock DeepSeek Cloudflare Edge FCM MIT

"Autonomous tech intelligence platform and Inshorts-style news reader built on a multi-repo distributed architecture."

ZeroDaily is a full-fledged, multi-repo tech intelligence ecosystem delivering 60-word roasted summaries across 7 technical and financial domains. The platform is decoupled into four dedicated subsystems: an offline-first mobile app client, a serverless REST & push notification backend, an autonomous LLM ingestion and media engine, and an edge-deployed web showcase with dynamic release resolution.

Multi-Repo Subsystems
  • Mobile App (err0rgod/zerodaily-app) — An Inshorts-style vertical gesture news reader built with React Native & Expo (SDK 52, TypeScript). Features 0ms cold-boot disk rendering, N-8 cursor prefetching engine, hardware-accelerated WebP caching, FCM topic subscriptions (topic_breaking_all & topic_{category}) with zero server-side device token tracking, and 100% cloud CI/CD APK builds via GitHub Actions.
  • Backend API & Stream Worker (err0rgod/zerodaily) — High-performance FastAPI serving layer on AWS Lambda (via Mangum) backed by DynamoDB single-table design with GSIs for cursor-based ISO-8601 pagination. Emits tuned Cloudflare edge caching headers for 10–20ms global responses. Includes an event-driven DynamoDB Streams worker enforcing atomic 30-minute anti-spam cooldowns per category with TTL locks to trigger FCM HTTP v1 breaking push notifications.
  • Ingestion & Dual-Persona Roasting Engine (err0rgod/bot1) — Containerized Python 3.12 AWS Lambda pipeline triggered every 3 hours by EventBridge across 24+ feeds. Uses AWS Bedrock DeepSeek v3.2 for semantic clustering (eliminating ~75% redundant fetches before extraction), multi-tier scraping (cloudscraper + Firecrawl fallback), prompt injection sandboxing via XML boundaries, a zero-trust media pipeline with SSRF/private-IP guards streaming 800px WebP assets to S3, and automated 06:00 UTC executive morning digest emails via Resend.
  • Web Showcase & Release Portal (err0rgod/zerodaily-web) — High-impact, minimal landing application built with Vite and deployed to Cloudflare Pages edge. Integrates with the GitHub Releases API to dynamically resolve release metadata and provide instantaneous HTTP 302 redirects (/apk, /download) to the latest standalone Android build, complete with interactive 60-word roast previews across all 7 domains.

# Conduit

TypeScript MCP Native Messaging Chromium & Firefox MIT

"A local-first, security-conscious bridge between AI agents and a real browser."

Conduit connects MCP and CLI clients to a user's existing browser profile through an authenticated local daemon and Manifest V3 extension. It keeps browser policy, consent, and audit decisions on the user's machine while exposing structured accessibility trees and semantic element IDs.

Architecture
AI agent (MCP / CLI) ──► Authenticated Local Daemon (Node.js 22+) ──► Native Messaging ──► Extension (MV3) ──► Browser Tab
Multi-Repo Ecosystem
  • Core Daemon & CLI (err0rgod/conduit) — Owns transport, policy, and agent integration. Implements MCP server, typed CLI, P-256 proof-of-possession pairing, Zod runtime schema validation, narrow origin permissions, rate limiting, and redacted audit logs. Registers Native Messaging manifests across Chrome, Firefox, Edge, Brave, and Chromium.
  • Browser Extension (err0rgod/conduit-extension) — Manifest V3 extension executing browser commands. Generates accessibility snapshots with temporary numeric element IDs for resilient clicks, text input, scrolling, and tab orchestration without fragile CSS selectors.
  • Web Portal & Documentation (err0rgod/conduit-web) — Interactive documentation hub and product portal hosted on Cloudflare Pages and GitHub Pages.
Stack
TypeScript Node.js 22+ Model Context Protocol (MCP) Manifest V3 Native Messaging Zod Playwright pnpm

# FlexURL

Python / FastAPI PostgreSQL / SQLModel Redis & ARQ Cloudflare for SaaS Tailwind CSS

"Enterprise-grade URL shortening & link analytics platform with custom domain provisioning."

FlexURL is a production-grade URL management platform engineered around FastAPI, PostgreSQL, and Redis. It pairs high-speed caching and Snowflake/Base62 link redirection with an asynchronous background analytics pipeline, automated Cloudflare for SaaS custom domain provisioning, and Google Safe Browsing malware detection.

Architecture
Client Request ──► Nginx Reverse Proxy ──► FastAPI Backend (Base62 + Snowflake)
                        │                         │
                        ▼                         ├──► PostgreSQL (Persistence via SQLModel)
                  Redis Cache                     ├──► ARQ Worker (Geo-IP & Bot Analytics)
           (Rate Limits & Hot URLs)               ├──► Cloudflare SaaS (Custom Domains & SSL)
                                                  └──► Resend API (Dunning & Reports via Redis SET NX)
Highlights
  • High-Performance Redirects — Base62 alias resolution with Redis caching for instant redirection, password-protected links, expiry scheduling, and OS-specific routing (iOS vs Android).
  • Non-Blocking Analytics Pipeline — Redirect events stream to an ARQ background queue, parsing Geo-IP, browser, device, and bot signatures before batch-flushing to PostgreSQL.
  • Branded Domains via Cloudflare SaaS — Programmatically provisions multi-tenant custom domains with automatic DNS CNAME verification and SSL certificate issuance.
  • Security & Abuse Prevention — Asynchronous Google Safe Browsing checks to automatically flag and block phishing or malware destinations.
  • Monetization & Developer API — Firebase Admin SDK authentication, JWT session cookies, Razorpay tier gating, API key management, and dynamic SVG GitHub visitor badges.

# Tokenly-Auth

Python PyPI Argon2id JWT MIT

"Database-agnostic authentication & session management for Python."

Tokenly-Auth is a lightweight security toolkit on PyPI that centralizes password hashing, JWT token lifecycle management, and refresh-token rotation without enforcing any specific database ORM or driver. The project includes a full reference implementation app and documentation portal.

Multi-Repo Subsystems
  • Core Library (err0rgod/tokenly) — Argon2id hashing with brute-force delay protection, JWT access and refresh token pair generation, secure refresh token hash storage, storage-agnostic rate limiting, and @require_auth decorators.
  • Demo Application & Test Suite (err0rgod/tokenly-app) — FastAPI reference application demonstrating user signup/login, session lifecycle management, token rotation, token blacklisting/revocation, and integration tests.
  • Documentation Hub (err0rgod/tokenly-auth-docs) — Architectural docs and implementation guides for integrating Tokenly-Auth into Python web services.
Install
# PyPI
pip install tokenly-auth
# issue a token pair
handler = TokenHandler(SECRET_KEY=...)

# protect a route

# MidAnalyzer

Python / Streamlit Docker Network Forensics MIT

"Browser-based PCAP analysis, without hosted-tool limits."

MidAnalyzer is a Streamlit-based forensic tool for analyzing packet capture (.pcap) files directly in the browser and extracting structured network telemetry. Built to sidestep cloud file-size restrictions and processing bottlenecks, it runs either hosted or locally via Docker with unlimited file capacity as part of the Midstalker MITM security framework.

Highlights
  • Interactive Forensics UI — Streamlit interface for exploring conversation flows, DNS resolutions, protocol distributions, and packet payloads.
  • No Size Limits via Docker — Local Docker execution processes multi-gigabyte captures using system resources directly, eliminating cloud upload caps.
  • Part of Midstalker Framework — Security tooling engineered for analyzing MITM vectors and inspecting network telemetry.
Run locally (Docker)
git clone https://github.com/err0rgod/midanalyzer.git
cd midanalyzer
docker build -t midstalker .
docker run -p 8501:8501 midstalker
# open http://localhost:8501

# blackwidow

C++ / ATtiny85 Digispark Hardware Security ★ 2 MIT

"Hardware HID takeover device bypassing Windows Defender Tamper Protection."

A specialized hardware attack device engineered on the ATtiny85 microcontroller (Digispark) for controlled penetration testing. It demonstrates physical-access threat vectors by automating GUI key sequences to disable Windows Defender Tamper Protection and Firewall, staging an elevated hidden reverse shell.

Attack Chain & Mechanics
  • Tamper Protection GUI Bypass — Windows Defender Tamper Protection cannot be turned off via CLI or PowerShell; the device executes timed keyboard navigation strokes via DigiKeyboard.h to toggle it off through the Windows Security GUI.
  • Privilege Elevation — Automates privileged terminal execution (Win+X → A → Y) to launch an elevated administrative command environment.
  • Defensive Neutralization — Disables all Windows Firewall profiles (netsh advfirewall set allprofiles state off) and halts Real-time Monitoring (Set-MpPreference -DisableRealtimeMonitoring $true).
  • Hidden Reverse Shell Stager — Downloads a netcat binary into memory via PowerShell and establishes a hidden reverse shell (-w Hidden) back to the listener.
  • Lab Documentation — Accompanied by in-depth Windows evasion analysis and operational workflows documented in the Mafia/ directory.
⚠ Authorized lab research only. Test hardware payloads exclusively on systems you own or have explicit permission to assess.
