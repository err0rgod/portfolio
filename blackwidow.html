blackwidow Lab-only HID research

Authorized lab research. An ATtiny85A that enumerates as a keyboard and exercises Windows tamper protection. Not a product.

§1The device

ATtiny85A · 8 pins · 8 KB flash · unlimited audacity

§2The chain

Plug in → ~30 seconds → it's over

  • Tamper Protection GUI bypass - Windows Defender's Tamper Protection can't be disabled from CLI or PowerShell (that's the entire point of it). So blackwidow doesn't argue with it: it navigates the Windows Security GUI with timed DigiKeyboard strokes and toggles it off like a user would - just inhumanly fast.
  • Privilege elevation - automates the Win+X → A → Y sequence to spawn an elevated admin terminal via UAC auto-accept.
  • Defensive neutralization - netsh advfirewall set allprofiles state off kills every firewall profile; Set-MpPreference -DisableRealtimeMonitoring $true halts real-time monitoring.
  • Hidden reverse shell - pulls a netcat binary down through PowerShell and stages a -w Hidden reverse shell back to the listener. No window, no taskbar, no mercy.
  • Documented like a lab, not a gist - the repo's Mafia/ directory holds the full Windows-evasion analysis and operational workflows.

§3Why hardware

Software exploits get patched; HID is a feature

  • It's a keyboard, not malware - the OS sees a HID device. No signature to match, no heuristic to trip, no file to scan. The payload is keystrokes.
  • $2 of silicon - the ATtiny85A (Digispark) costs less than the USB cable it arrives with. Physical-access threat modeling at disposable prices.
  • Timing as an exploit primitive - the whole attack is choreographed delays and keystrokes. Getting sub-second GUI navigation reliable across Windows versions is genuinely hard - and that's the fun part.
  • Physical access = game over - the real lesson: if someone can plug something into your machine, your threat model already lost. blackwidow demonstrates it in 30 seconds.
