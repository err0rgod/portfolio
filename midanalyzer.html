What it reads

Wireshark answers, browser ergonomics

  • Conversation flows - who talked to whom, when, how often. The first question in any capture, answered visually.
  • DNS resolutions - every lookup in the capture, surfaced and searchable. Suspicious domains don't get to hide in packet 48,291.
  • Protocol distribution - the shape of the traffic at a glance; weird ratios stand out immediately.
  • Packet payload inspection - drill into individual packets when the summary isn't enough.
  • Docker mode for the big ones - docker run -p 8501:8501 midstalker and your machine's resources are the limit, not some hosted tool's upload form.
  • MITM-framework native - built as the analysis arm of the Midstalker framework: engineered for inspecting man-in-the-middle vectors and network telemetry.

Run it

Four lines to forensics

git clone https://github.com/err0rgod/midanalyzer.git
cd midanalyzer
docker build -t midstalker .
docker run -p 8501:8501 midstalker
# → http://localhost:8501 - feed it a pcap
